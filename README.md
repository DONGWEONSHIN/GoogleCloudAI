# GoogleCloudAI

## 📌 프로젝트 개요
이 레포지토리는 **시니어 자바 개발자**가 AI 학습을 위해 배운 내용을 정리한 것입니다. 10년 이상의 개발 경력을 가진 상태에서 처음 접하는 AI의 방대한 영역은 놀라움과 겸손함을 동시에 느끼게 했습니다. 특히, 학습 초반에는 완전히 새로운 개념과 도구들에 적응하기 위해 많은 노력이 필요했습니다. 하지만 중후반으로 접어들면서 AI 학습의 궤도에 안착했고, 꾸준히 즐기며 학습을 이어갈 수 있었습니다. 프로젝트를 수행하면서 상위 성과를 거두었으며, 후반부에는 교육생들에게 도움을 제공하며 여유를 찾을 수 있었습니다.
GoogleCloudAI는 **Google Cloud를 활용한 AI 개발 교육**을 지원하기 위한 레포지토리입니다. 이 레포지토리는 데이터 분석, 머신러닝, 딥러닝, YOLO를 활용한 객체 탐지, Google Cloud를 이용한 AI 배포와 같은 다양한 주제를 학습하고 실습할 수 있도록 설계되었습니다.

## 📂 주요 구성 요소

### 1. [교육 자료 (`edu` 디렉토리)](./edu)
**교육용 Jupyter 노트북과 스크립트를 포함**하며, 주요 주제는 다음과 같습니다:
- **[파이썬 기초](./edu/python_basics.ipynb)**: 파이썬의 기본 문법 및 프로그래밍 개념 학습.
- **[EDA 및 데이터 분석](./edu/data_analysis.ipynb)**: 데이터를 탐색하고 시각화하는 방법.
- **[머신러닝 기초](./edu/machine_learning_intro.ipynb)**: 머신러닝의 기본 개념과 주요 알고리즘 학습.
- **[딥러닝 및 신경망](./edu/deep_learning_intro.ipynb)**: 딥러닝의 구조와 신경망 모델 구축.
- **[YOLO 객체 탐지](./edu/yolo_object_detection.ipynb)**: YOLO를 활용한 객체 탐지 실습.
- **[Google Cloud를 활용한 AI](./edu/google_cloud_ai.ipynb)**: Google Cloud에서 AI 모델 배포 및 관리.

### 2. [프로젝트 예제 (`project` 디렉토리)](./project)
**학습한 내용을 실제로 적용할 수 있는 프로젝트 예제**를 제공합니다:
- **[데이터 분석 프로젝트](./project/project1)**: 데이터셋 전처리, 분석, 시각화.
- **[머신러닝 모델 프로젝트](./project/project2)**: 모델 학습 및 평가.
- **[딥러닝 이미지 분류 프로젝트](./project/project3)**: 신경망을 활용한 이미지 분류.
- **[YOLO 객체 탐지 프로젝트](./project/project4)**: 영상 데이터에서 객체 탐지 모델 구현.
- **[Google Cloud AI 배포 프로젝트](./project/project5)**: 클라우드 환경에서 AI 모델 배포.

### 3. [환경 설정 및 가이드](./README.md)
- **Git 설정 및 관리**: Git 토큰 변경, 원격 저장소 업데이트 등.

## 🌟 학습 목표
1. Google Cloud를 활용하여 AI 개발 전반의 과정을 학습.
2. 데이터 분석 및 EDA를 통해 데이터의 특성을 이해.
3. 머신러닝과 딥러닝 알고리즘을 활용한 모델 구축 및 평가.
4. YOLO를 이용해 객체 탐지 모델을 실습.
5. Google Cloud에서 AI 모델을 배포 및 운영.

## 🚀 시작하기

### 1. 레포지토리 클론
```bash
git clone https://github.com/DONGWEONSHIN/GoogleCloudAI.git
```

### 2. 디렉토리 이동
```bash
cd GoogleCloudAI
```

### 3. 필수 패키지 설치
```bash
pip install -r requirements.txt
```

### 4. Jupyter 노트북 실행
```bash
jupyter notebook
```
