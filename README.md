# GoogleCloudAI

## 📌 프로젝트 개요

이 레포지토리는 **시니어 자바 개발자**가 AI 학습을 위해 배운 내용을 정리한 것입니다. 10년 이상의 개발 경력을 가진 상태에서 처음 접하는 AI의 방대한 영역은 놀라움과 겸손함을 동시에 느끼게 했습니다. 특히, 학습 초반에는 완전히 새로운 개념과 도구들에 적응하기 위해 많은 노력이 필요했습니다. 하지만 중후반으로 접어들면서 AI 학습의 궤도에 안착했고, 꾸준히 즐기며 학습을 이어갈 수 있었습니다. 프로젝트를 수행하면서 상위 성과를 거두었으며, 후반부에는 교육생들에게 도움을 제공하며 여유를 찾을 수 있었습니다.
GoogleCloudAI는 **Google Cloud를 활용한 AI 개발 교육**을 지원하기 위한 레포지토리입니다. 이 레포지토리는 데이터 분석, 머신러닝, 딥러닝, YOLO를 활용한 객체 탐지, Google Cloud를 이용한 AI 배포와 같은 다양한 주제를 학습하고 실습할 수 있도록 설계되었습니다.

---

## 📂 주요 학습 내용

### 1. [파이썬 기초](./edu/python)
- **내용 요약**: 파이썬의 기본 문법과 프로그래밍 개념을 학습.
- **주요 학습 사항**:
  - 변수, 데이터 타입, 조건문, 반복문
  - 함수 및 모듈 활용

### 2. [데이터 분석 및 EDA](./edu/data_analysis)
- **내용 요약**: 데이터를 탐색하고 시각화하는 방법을 익힘.
- **주요 학습 사항**:
  - 데이터 정제 및 전처리
  - Pandas와 Matplotlib을 이용한 데이터 시각화

### 3. [머신러닝 기초](./edu/machine_learning)
- **내용 요약**: 머신러닝의 기본 개념과 주요 알고리즘 학습.
- **주요 학습 사항**:
  - 지도 학습과 비지도 학습
  - Scikit-learn을 활용한 모델 학습 및 평가

### 4. [딥러닝 및 신경망](./edu/deep_learning)
- **내용 요약**: 딥러닝의 구조와 신경망 모델 구축 방법 학습.
- **주요 학습 사항**:
  - 신경망의 구조 및 역전파 원리
  - TensorFlow/Keras를 이용한 모델 구현

### 5. [YOLO를 활용한 객체 탐지](./edu/yolov8)
- **내용 요약**: YOLO 모델을 활용하여 객체 탐지 실습 진행.
- **주요 학습 사항**:
  - YOLO의 원리 및 모델 구조
  - 학습 및 테스트 데이터 준비 방법

### 6. [Google Cloud를 활용한 AI 배포](./edu/google_cloud)
- **내용 요약**: Google Cloud Platform을 활용하여 AI 모델을 배포하고 관리하는 방법 학습.
- **주요 학습 사항**:
  - GCP 환경 설정 및 AI 도구 사용법
  - 모델 배포 및 서버리스 환경 구축

## 🚀 시작하기

### 1. 레포지토리 클론
```bash
git clone https://github.com/DONGWEONSHIN/GoogleCloudAI.git
```

### 2. 디렉토리 이동
```bash
cd GoogleCloudAI
```

### 3. 필수 패키지 설치
각 Jupyter 노트북을 실행하기 전에, 해당 노트북의 첫 번째 셀에 명시된 패키지들을 설치하세요. 일반적으로 다음과 같은 명령어를 사용합니다:

```bash
pip install 패키지이름
```

### 4. Jupyter 노트북 실행
```bash
jupyter notebook
```
